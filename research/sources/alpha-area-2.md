Documented evidence:
• An Insight is a prediction for an asset, with direction and optional magnitude, confidence, source_model, weight, tag, and prediction period/expiry. Alpha outputs Insights, not final executable orders. Portfolio construction determines how they become PortfolioTargets; default down/up interpretations are short/long, while flat usually closes positions, but custom construction can differ.
• Portfolio construction receives Insights and creates PortfolioTargets for risk management. A PortfolioTarget represents number of asset units to hold (desired position), not necessarily an incremental trade. Percent helper converts portfolio weights to targets; docs say this helper is available only for margin accounts.
• Multiple alpha models produce a combined Insight stream. Critically, the base construction model used by most PCMs selects the most recent active Insight per Symbol rather than combining same-symbol Insights. Combining all active Insights requires overriding get_target_insights and defining combination criteria in determine_target_percent. Therefore automatic ensemble netting must not be assumed.
• Target collection excludes targets already satisfied by current holdings plus open-order quantity. This is documented reconciliation, not evidence that independently sized strategy portfolios automatically net correctly.
• Signal Exports transmits algorithm trading/portfolio state to a fund or third-party service; custom providers receive PortfolioTarget lists. Automatic export occurs when holdings change, with a default five-second post-fill aggregation delay; manual targets and disabling automatic exports are supported. This is downstream position transport, distinct from upstream alpha predictions.
