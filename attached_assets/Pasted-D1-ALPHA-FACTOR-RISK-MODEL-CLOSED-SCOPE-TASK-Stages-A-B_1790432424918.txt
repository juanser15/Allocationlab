D1 — ALPHA FACTOR RISK MODEL

CLOSED-SCOPE TASK

Stages A, B, C1, C2 and C3 are CLOSED.

GOAL

Add a genuine statistical factor risk model for TRADABLE ALPHA STREAMS
and make it an alternative risk estimator inside the existing B2/B3
optimization workflow.

D1 changes HOW joint alpha risk is estimated.

It does NOT:
- create new alphas;
- select alphas;
- remove correlated alphas;
- change C3 grouping policies;
- optimize raw signals;
- add signed alpha weights;
- add leverage;
- add transaction costs to the optimizer objective;
- implement liquidity/capacity;
- run PCA as an alpha-selection method.

PCA in D1 is used ONLY to construct a statistical covariance/risk model.

--------------------------------------------------
1. RISK MODEL OPTIONS
--------------------------------------------------

For alpha-stream optimization expose three explicit risk-model choices:

A. SAMPLE_COVARIANCE

Sigma = S

B. DIAGONAL_SHRINKAGE

Existing B2 methodology:

Sigma =
(1 - delta) S
+ delta diag(S)

C. STATISTICAL_FACTOR_MODEL

New D1 methodology:

Gamma =
Xi + Omega Phi Omega'

The B2 expected-return estimator, objective, constraints and solver remain
unchanged.

Only the covariance/risk estimator changes.

Asset-return mode keeps its existing supported risk models.
D1 statistical factor modeling is initially for ALPHA STREAMS.

Do not silently substitute one estimator for another.

--------------------------------------------------
2. INPUT DATA
--------------------------------------------------

Use the same aligned gross daily alpha-stream returns currently used by
B2 for covariance estimation.

Do not use:
- raw signal scores;
- final underlying asset returns;
- future observations;
- net returns after standalone alpha transaction costs as a substitute
  for the existing B2 gross-return convention.

For every as-of calculation record:

- candidate IDs;

- observation count T;

- information cutoff;
- B1 preparation identity;
- dataset identity/hash.

All observations must end at or before the valid point-in-time cutoff.

No missing returns may be silently replaced by zero.

--------------------------------------------------
3. SAMPLE COVARIANCE
--------------------------------------------------

Given aligned alpha return matrix X with T observations and N alphas:

Center each alpha using only the estimation window.

Compute:

S =
1 / (T - 1) * X_centered' X_centered

Use daily decimal returns.

Record:
- diagonal variances;
- correlation matrix;
- eigenvalues;
- rank;
- condition diagnostics.

Do not annualize Sigma inside the solver.

Annualized risk display may multiply daily variance by 252 only at the
reporting layer.

--------------------------------------------------
4. STATISTICAL FACTOR MODEL CONSTRUCTION
--------------------------------------------------

Construct the factor model from the SAMPLE CORRELATION matrix.

Let:

D = diag(sigma_1, ..., sigma_N)

where sigma_i is the sample standard deviation of alpha i.

Correlation matrix:

R =
D^(-1) S D^(-1)

Compute:

R =
V Lambda V'

Order eigenvalues:

lambda_1 >= lambda_2 >= ... >= lambda_N

Use a FIXED user-visible factor count F.

Do not choose F by maximizing historical portfolio performance.

Default:

F = min(5, N - 1, T - 1)

The actual selected F must be visible, editable and frozen.

If the user explicitly selects F, do NOT silently lower it later.

Require:

1 <= F < N
and
F < T

If not satisfied:

INSUFFICIENT_HISTORY_OR_DIMENSION

Do not silently change F.

--------------------------------------------------
5. FACTOR COVARIANCE REPRESENTATION
--------------------------------------------------

Let V_F contain the first F eigenvectors and Lambda_F their eigenvalues.

Define:

Omega =
D V_F

Phi =
diag(lambda_1, ..., lambda_F)

Then common covariance is:

C_common =
Omega Phi Omega'

Raw specific variance:

xi_i_raw^2 =
S_ii - (C_common)_ii

Numerical negative values inside declared floating-point tolerance may
be set to zero.

Materially negative specific variance must return:

INVALID_FACTOR_MODEL

Do not silently repair a materially invalid decomposition.

--------------------------------------------------
6. SPECIFIC-RISK FLOOR
--------------------------------------------------

For numerical stability support an explicit user-visible parameter:

specificRiskFloorFraction >= 0

Define:

xi_i^2 =
max(
    xi_i_raw^2,
    specificRiskFloorFraction * S_ii
)

Default:

specificRiskFloorFraction = 1e-6

This is a numerical regularization assumption.

It must:
- be visible;
- be versioned;
- be included in snapshots;
- report which alphas are floor-bound.

Do not call it empirical alpha risk.

Final model:

Xi =
diag(xi_1^2, ..., xi_N^2)

Gamma =
Xi + Omega Phi Omega'

Report explicitly if the risk floor makes Gamma's diagonal differ from
the raw sample variance.

--------------------------------------------------
7. PCA BASIS DETERMINISM
--------------------------------------------------

Order factors by descending eigenvalue.

For each eigenvector apply a deterministic sign convention:

Locate the loading with largest absolute magnitude.
Make that loading positive.

Persist:
- ordered eigenvalues;
- canonicalized eigenvectors/loadings.

If adjacent eigenvalues are nearly tied according to a documented
relative eigen-gap tolerance, flag:

FACTOR_BASIS_UNSTABLE

This warning does NOT invalidate Gamma.

Do not interpret individual PCA-factor names economically.

Use labels:

Statistical Factor 1
Statistical Factor 2
...

PCA factors are risk directions, not alpha signals.

--------------------------------------------------
8. VALIDATION OF GAMMA
--------------------------------------------------

Before B2 uses Gamma verify:

- all entries finite;
- symmetry within tolerance;
- positive semidefinite within tolerance;
- dimensions match candidate ordering;
- specific variances nonnegative;
- factor count valid.

Report:

- min eigenvalue;
- max eigenvalue;
- condition number when defined;
- numerical rank;
- effective rank.

Effective rank:

p_j =
lambda_j / sum(lambda)

EffectiveRank =
exp(
  -sum_j p_j log(p_j)
)

Use only positive eigenvalues for this diagnostic and state the
convention.

A materially invalid Gamma returns:

INVALID_RISK_MODEL

Never substitute equal weights or another covariance estimator.

--------------------------------------------------
9. RISK DECOMPOSITION
--------------------------------------------------

For portfolio alpha weights b:

Portfolio variance:

Var_p =
b' Gamma b

Portfolio volatility:

sigma_p =
sqrt(Var_p)

FACTOR RISK

Factor exposure:

f =
Omega' b

Factor variance:

Var_factor =
f' Phi f

Per-factor variance contribution:

FC_A =
f_A * (Phi f)_A

Require:

sum_A FC_A =
Var_factor

within numerical tolerance.

SPECIFIC RISK

Specific variance:

Var_specific =
sum_i b_i^2 xi_i^2

Require:

Var_p =
Var_factor + Var_specific

within numerical tolerance.

ALPHA MARGINAL/COMPONENT RISK

For sigma_p > 0:

MRC_i =
(Gamma b)_i / sigma_p

CRC_i =
b_i * MRC_i

Require:

sum_i CRC_i =
sigma_p

within numerical tolerance.

If portfolio volatility is zero, relevant ratios remain undefined.

Do not fabricate values.
