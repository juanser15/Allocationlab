---
name: Allocation Lab navigation boundaries
description: Keep additional workflows within the existing navigation and preserve the global configuration entry point.
---

Do not add a top-level navigation item for each allocation, validation, or research sub-workflow. Keep the main Portfolio Lab workflow vertical, with advanced tools progressively disclosed. Settings belongs to the global configuration drawer, not a new sidebar destination.

**Why:** Repeated navigation restructuring made it harder to distinguish the main portfolio workflow from supporting tools. The bounded Portfolio Lab restructuring prioritizes a clear primary flow without expanding the application's navigation.

**How to apply:** Inspect the current navigation instead of restoring an old memorized item count. Add supporting workflows within existing destinations; change top-level navigation only when explicitly requested.
